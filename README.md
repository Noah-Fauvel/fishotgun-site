# Fishotgun

Site de présentation de **Fishotgun**, un jeu de pêche solo ou multijoueur dans lequel un lapin attrape des poissons au fusil à pompe, remplit son Fishodex, améliore son équipement et échange avec les autres joueurs. Le jeu a été développé par l'équipe Rabbit Hole dans le cadre du cycle préparatoire de l'EPITA Toulouse (2025-2026).

Ce dépôt héberge le site et les documents du projet :

- la page de présentation (jeu, galerie, feuille de route, équipe), en français et en anglais ;
- les documents dans `assets/docs/` : guide d'installation et rapport de soutenance final.
